2. 기술 명세

| 2.1 기술목적 | 비전: "문제를 정의·해결하고 설명할 수 있는 개발자를 길러낸다."전략: "교육기관이 대규모로 도입 가능한 통제형 기술면접 평가 시스템을 구축한다."기존 코딩 테스트는 정답 여부만 평가하고, 범용 LLM 면접은 질문 통제·사실 정확도·비용 측면에서 기관 도입이 어렵다. 본 기술은 문제별 Fact/Trap 데이터와 코드 기반 분석을 결합하여 문제 정의·해결 논리·설명 역량을 반복·통제 가능한 방식으로 평가하며, 기관이 저비용으로 기술면접 훈련과 약점 진단을 운영할 수 있도록 한다. |
| --- | --- |
| 2.2 기술구조 | [4계층 아키텍처]1. 문제 가이드 레이어: 문제별 optimal solution·follow-up goal·forbidden boundary·trap을 JSON으로 관리. LLM의 질문 생성 범위를 통제하는 '조종간(Fact)' 역할2. 코드 프로파일 레이어: Python ast.NodeVisitor로 중첩 루프·위험 연산·재귀 패턴·Cyclomatic Complexity를 추출하여 Trap 매칭과 질문 트리거로 연결. 채점은 Judge0 API 연동으로 자체 서버 비용 최소화3. 인터뷰 오케스트레이션 레이어: Deterministic First 상태 분기 — CC≥15·파싱 실패 시 FallbackFlow, 위험 연산 0건·중첩 루프 낮을 시 PlanBFlow, 그 외 NormalFlow. 모델 미연동 시 규칙 기반 fallback 질문으로 세션 지속4. 평가 및 리포트 레이어: 3\~4턴 대화 로그를 정의·해결·설명 3축 리포트로 생성(모델 미연동 시 fallback). 세션 데이터는 기관/학습자 피드백 자산으로 축적 |
| 2.3 주요기능 | [MVP 핵심 기능]1) 통제형 질문 생성: Fact/Trap/Forbidden Boundary 범위 내에서만 질문 생성, Trap 기반 follow-up으로 취약점 정밀 탐색2) 코드 근거 기반 분기: AST 신호에 따라 NormalFlow/PlanBFlow/FallbackFlow 자동 전환, 질문 근거를 코드로 설명3) 3축 평가: 면접 종료 후 정의/해결/설명 기반 리포트 자동 생성4) 기관 운영 확장: 세션 데이터 저장, 수강생별 약점 축적, 강사 검수/대시보드 확장5) 수단 확장성: 동일 스키마를 케이스 면접·시스템 설계·실무 문제 정의 훈련으로 이식 가능[Post-MVP 확장 기능]- (신뢰도) 강사가 AI 평가를 보정하는 휴먼 오버라이드(Human-Override) 대시보드- (확장성) 강사 전용 Fact/Trap JSON 저작 도구 (AI Trap 후보 자동 생성 → 강사 검수) |
| 2.4 결과물 형상 | 웹 기반 SaaS 플랫폼 (채용 기관, 교육 기관 타겟 B2B 애플리케이션 형태) |
| 2.5 배포방식 | 반응형 웹 애플리케이션 기반 배포 (프론트/백엔드/데이터 스토어 연동 클라우드 인프라 활용) |
| 2.6 혁신적 요소 | 본 기술의 혁신은 자유 대화형 AI 면접이 아니라 '검수 가능한 질문 생성 구조'에 있다. AI가 무엇을 묻지 말아야 하는지까지 구조적으로 제한하며, 코드 프로파일과 문제 가이드를 결합해 질문 근거를 남긴다.- Fact 주입 + 코드 분기 결합: 문제별 Fact/Trap을 컨텍스트로 주입하고 AST 분석 + 규칙 기반 분기로 질문 흐름을 제어하여, 범용 LLM보다 문제 맥락에 맞는 질문을 안정적으로 생성- Text-first MVP 안정성: Monaco 코드 제출, Judge0 연동 또는 Demo Mode, 모델 미연동 시 fallback 질문/리포트로 외부 의존성 불안정 상황에도 데모 완주 |
| 2.7 도전적 요소 | 본 기술의 핵심 도전 과제는 모델 성능 자체보다 제어, 안정성, 운영 가능성이다.1) 양극단 엣지 케이스 처리: 스파게티 코드에서는 FallbackFlow(핵심 개념 질문), 약점 적은 풀이에서는 PlanBFlow(스케일업 압박) — 양극단을 하나의 상태 기반 분기 로직으로 처리해야 한다.2) 외부 의존성 하의 데모 안정성: Judge0·LLM 미연동 상황에서도 Demo Mode와 fallback으로 세션을 지속하도록 설계. 결정론적 데모 스크립트로 외부 API 불안정 시에도 핵심 가치를 완주 전달한다. |

### Q1. 나의 아이디어를 한 줄로 소개해주세요. (필수)
*(최소 10자 이상, 100자 이내)*

제출 코드를 읽고 근거 있는 꼬리질문과 피드백을 제공하는 교육기관용 AI 기술면접 훈련 솔루션입니다.

### Q2. 아이디어를 떠올린 배경 이야기를 들려주세요. (필수)
*(최대 1000자 이내, 사진 삽입 가능)*

개발자 취업 과정에서 코딩테스트 합격은 끝이 아니라 기술면접의 시작입니다. 많은 취업준비생은 문제를 풀 수는 있지만, 면접에서 “왜 이 자료구조를 선택했는지”, “시간복잡도를 어떻게 판단했는지”, “조건이 바뀌면 코드를 어떻게 고칠지”를 설명하는 데 어려움을 겪습니다. 결국 합격을 가르는 것은 정답 코드 자체보다 자신의 코드를 이해하고 설명하며 방어할 수 있는 역량입니다.

이 문제는 생성형 AI 확산 이후 더 커졌습니다. 이제는 정답 코드와 실행 결과를 빠르게 만드는 일은 쉬워졌지만, 그 코드가 지원자의 실제 이해에서 나온 것인지는 더 확인하기 어려워졌습니다. 기존 코딩테스트 플랫폼은 정답 여부 중심이고, 범용 AI 면접 서비스는 제출 코드의 맥락을 충분히 반영하지 못해 일반적인 질문에 머무르는 경우가 많습니다.

반면 코딩 부트캠프와 국비 개발자 교육기관은 수강생의 취업률을 높이기 위해 기술면접 훈련까지 책임져야 합니다. 하지만 수강생마다 제출 코드가 다르고, 모든 코드에 대해 멘토가 직접 질문을 만들고 피드백을 주기에는 인력과 시간이 부족합니다. 저희는 이 지점에서, 수강생이 작성한 코드를 출발점으로 삼아 코드 속 판단 근거를 찾고 그에 맞는 꼬리질문과 피드백을 제공하는 방식이 필요하다고 보았습니다.

### Q3. 아이디어는 누구의 어떤 문제를 해결해주나요? (필수)
*(최대 1000자 이내, 사진 삽입 가능)*

직접 사용자는 취업준비생이지만, 초기 구매자는 코딩 부트캠프와 국비 개발자 교육기관입니다. 이들은 수강생의 취업 성과를 높여야 하지만, 실제 현장에서는 기술면접 훈련을 수강생별로 반복 가능하고 일관된 방식으로 운영하기 어렵습니다.

교육기관의 핵심 문제는 세 가지입니다. 첫째, 수강생별 제출 코드를 보고 맞춤형 질문을 만들 멘토 시간이 부족합니다. 둘째, 멘토마다 피드백 기준이 달라 수강생의 약점을 일관되게 관리하기 어렵습니다. 셋째, 운영진은 수강생의 설명 능력·문제 이해도·구현 사고력이 실제로 나아지고 있는지를 구조적으로 확인하기 어렵습니다.

소크라틱 딥다이브는 이 문제를 코드 기반 AI 모의면접으로 해결합니다. 수강생이 제출한 코드를 분석해 자료구조 선택, 제어 흐름, 복잡도, 예외 처리, 경계값 같은 질문 포인트를 찾고, 그 근거에 맞는 꼬리질문과 3축 피드백 리포트를 제공합니다. 이를 통해 교육기관은 취업 성과 개선, 멘토 운영 부담 완화, 피드백 품질 표준화를 동시에 기대할 수 있고, 수강생은 자신의 코드로 질문받는 훈련을 반복하며 실제 면접 대응력을 높일 수 있습니다. 초기에는 교육기관용 B2B 솔루션으로 집중하고, 이후 기업의 1차 기술 검증 보조 리포트와 개인용 면접 훈련 서비스로 확장하고자 합니다.

### Q4. 아이디어를 어떻게 실현하고 싶으신가요? (필수)
*(최대 1000자 이내, 사진 삽입 가능)*

저희는 소크라틱 딥다이브를 코딩테스트 결과와 기술면접 사이의 빈 구간을 메우는 교육기관용 SaaS로 실현하고자 합니다. 핵심 MVP 흐름은 코드 제출, 질문 근거 추출, AI 꼬리질문, 3축 피드백 리포트입니다. 단순히 AI가 질문을 생성하는 서비스가 아니라, 사용자가 실제로 제출한 코드에서 질문 근거를 찾아 면접을 진행하는 점이 차별점입니다.

![서비스 흐름도 삽입 위치 - docs/modoo_startup/assets/socratic_deepdive_service_flow.png]

사용자가 코딩 문제 풀이 코드를 제출하면 시스템은 자료구조 선택, 제어 흐름, 시간복잡도 단서, 예외 처리 누락, 경계값 처리 여부를 분석합니다. 이후 문제별 Fact·Trap 데이터와 연결해 “왜 이 방식으로 풀었는가”, “입력 크기가 커지면 병목은 어디인가”, “조건이 바뀌면 어떤 부분을 수정해야 하는가” 같은 실전형 꼬리질문을 생성합니다. 답변 후에는 문제 이해도, 구현 사고력, 설명 능력 기준으로 리포트를 제공해 수강생과 교육기관이 같은 기준으로 약점을 확인할 수 있게 만들고자 합니다.

실행은 작은 검증부터 시작하겠습니다. 먼저 핵심 MVP에서 코드 제출부터 질문 근거 추출, AI 꼬리질문, 3축 피드백 리포트까지의 흐름을 구체화하고, 20명 내외 규모의 교육기관 파일럿을 통해 실제 수강생 사용성과 교육기관의 운영 적합성을 확인할 계획입니다. 이 과정에서 강사 피드백과 AI 리포트의 일치도, 수강생 답변 품질 변화, 멘토가 실제 수업 운영에 활용할 수 있는지를 핵심 지표로 검증하겠습니다. 이를 바탕으로 관리자 화면, 수강생별 리포트 누적, 문제 세트 관리 기능을 붙여 교육기관용 B2B SaaS로 확장하고, 장기적으로는 기업의 1차 기술 검증 보조 리포트와 개인용 면접 훈련 서비스까지 넓혀가고자 합니다.
